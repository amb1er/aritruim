# Aster USDT perpetuals

Подключён официальный публичный Futures V3 API `https://fapi.asterdex.com`.
API-ключ не нужен. В `.env` включено `ASTER_ENABLED=true`. Изменения применяются
при следующем запуске; работающий процесс автоматически не перезапускался.

Поддержка: сканирование perp–perp и spot-long/perp-short через существующий
сканер, общие условия входа/выхода, cooldown, paper-баланс, уведомления о
paper-позициях. Реальные ордера, подписи и операции аккаунта не реализованы.

## Рыночные данные

- `/fapi/v3/exchangeInfo`: только `TRADING`, `PERPETUAL`, quote/margin `USDT`.
  USD1 и U рынки исключены, чтобы не смешивать разные расчётные активы.
- `/fapi/v3/fundingInfo`: интервал каждого контракта; если интервал неизвестен,
  ставка не допускается в сканер. Фиксированного предположения «везде 8 часов» нет.
- `/fapi/v3/premiumIndex`: ставка, mark price и следующая выплата. `lastFundingRate`
  используется как текущая оценка carry, а не гарантированная будущая выплата.
- `/fapi/v3/depth`: обе стороны стакана, глубина и время снимка.
- `/fapi/v3/fundingRate`: применённые ставки и время выплаты с пагинацией.

Метаданные обновляются раз в 5 минут. Список нормализованных рынков фиксируется
при запуске, как у остальных адаптеров. Существующая модель `period_history`
начисляет paper-funding по событиям истории; reference price — наблюдаемая mark
price около события, поэтому сумма остаётся оценкой, а не выпиской аккаунта.

## Комиссии

Введены раздельные настраиваемые предположения без VIP-скидок:

| Настройка | Значение | Процент |
| --- | --- | --- |
| ASTER_MAKER_FEE | 0 | 0% |
| ASTER_TAKER_FEE | 0.0004 | 0,04% |
| ASTER_GROUP_B_TAKER_FEE | 0.001 | 0,1% |
| ASTER_RWA_TAKER_FEE | 0.000125 | 0,0125% |

Group B — явный список из документации, проверенный 27 сентября 2026;
RWA определяются по `symbolType=1` в метаданных. Если инструмент встречается
в Group B и RWA одновременно (например, SKHYNIX), применяется более высокая
ставка Group B. Индивидуальные комиссии аккаунта требуют авторизованного API
и сейчас не запрашиваются. Изменение списка категорий биржей требует обновления.

## Сопоставления

В локальный каталог добавлено 569 записей Aster из PerpDexList без изменения
снимков остальных площадок. Импортируются только исходные пары с суффиксом USDT.
Примеры: 1000PEPE → PEPE с множителем 1000, CL → WTIOIL, BZ → BRENTOIL.
Различные токены QNT и QNTX сохраняют различие, заданное источником.

При публичной проверке доступно 567 канонических рынков с интервалами 1/4/8 часов.
Группа BB исключена из-за неоднозначности BB/BBX. Число рынков может меняться.
После запуска для Aster требуется накопить историю, прежде чем станут возможны входы.
